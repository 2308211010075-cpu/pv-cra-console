Methodology note — This is a static portfolio demonstration. Modules 1–4 illustrate LLM-based reasoning against ICH E2A seriousness criteria, WHO-UMC causality logic, and MedDRA-style hierarchy approximation (no licensed MedDRA dictionary used) via pre-computed example outputs. Module 5 uses a fixed weighted-scoring formula consistent with ICH E6(R2) risk-based quality management principles, and runs live with any input. All output is for educational/portfolio demonstration only.
